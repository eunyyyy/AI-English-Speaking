# Daily English 웹앱

## 실행

가장 간단하게는 `app/index.html`을 최신 Chrome 또는 Edge로 열면 됩니다. 마이크 음성 인식은 브라우저 권한을 허용해야 하며, 브라우저에 따라 localhost 또는 HTTPS에서만 동작할 수 있습니다.

## 기능

- 오늘의 학습 대시보드와 학습 기록
- 단어장: 추천 단어 검색, 발음 듣기, 저장/해제
- 단어 공부: 플래시카드, 직접 단어 추가, 헷갈린 단어 저장
- 퀴즈: 오답 단어를 단어장에 자동 저장
- AI 영어 대화: 자유 대화와 상황극, 마이크 음성 입력, 브라우저 음성 출력
- 대화 중 추천 표현과 설명 카드, 추천 단어 단어장 저장

학습 데이터는 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 지우면 학습 기록도 초기화될 수 있으니, 중요한 단어는 별도 백업을 권장합니다.

## AI 응답 연결

현재 앱은 `/api/chat`에 서버 요청을 보냅니다. 응답 서버가 없거나 연결되지 않으면 체험용 내장 응답으로 대화가 계속됩니다. 생성형 모델을 실제 연결하려면 서버에서 `/api/chat`을 구현하고 AI 공급자의 비밀 키를 서버 환경 변수로 설정해야 합니다. 비밀 키를 `app.js`나 브라우저 코드에 넣지 마세요.

요청 본문은 `{ "messages": [{"role":"user|assistant","content":"..."}], "mode":"free|scenario", "scenario":{"title":"...","role":"..."} }` 형식입니다. 응답은 `{ "reply":"영어 답변" }` 형식으로 돌려주면 됩니다.

## 폴더

- `app/`: 웹앱 HTML, CSS, JavaScript
- `data/`: 초기 단어 데이터
- `docs/`: 사용 및 설정 안내
